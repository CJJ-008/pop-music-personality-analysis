# 流行音乐数据分析：什么性格的年轻人喜欢什么样的流行歌手

> 大数据专业个人项目 · Python + scikit-learn 全流程数据分析
> 用 1010 名年轻人的性格问卷与 28356 首 Spotify 歌曲数据，通过聚类、分类、回归三类算法，
> 量化「性格画像 → 音乐流派 → 代表歌手」的关联链路。

## 一、项目要解决的问题

音乐推荐系统通常只用「听了什么」做协同过滤，冷启动阶段无历史行为可用。
本项目换一个角度：**能否只用年轻人的性格与生活方式，就推断出他的音乐口味，从而在冷启动时直接推荐流派与歌手？**

为回答这个问题，项目拆成三个可验证的子问题：

1. 年轻人可以按性格分成哪几类画像？（**聚类**）
2. 能否用人口学与兴趣爱好预测一个人属于哪个画像？（**分类**）
3. 什么样的歌更容易流行？（**回归**）

## 二、数据来源

| 数据集 | 内容 | 规模 | 来源 |
|--------|------|------|------|
| Young People Survey | 15~30 岁年轻人问卷：17 个音乐流派 1-5 分偏好、性格与生活态度、人口学特征 | 1010 人 × 150 列 | [Kaggle](https://www.kaggle.com/datasets/miroslavsabo/young-people-survey) |
| Spotify Songs (TidyTuesday) | 六大流派歌曲的歌手、流行度、11 个音频特征 | 32833 首 → 去重后 **28356 首**，**10692 位歌手** | [TidyTuesday 2020-01-21](https://github.com/rfordatascience/tidytuesday/tree/main/data/2020/2020-01-21) |

数据获取全部脚本化：Spotify 数据从 GitHub 直链下载；问卷数据通过 `kagglehub` 自动拉取，
无需手动下载（见 `src/01_download_data.py`）。

## 三、分析方法与技术栈

```
问卷数据 ──► 清洗/缺失值填补 ──► 合成大五人格代理指标 ──► K-Means 聚类 ──► 3 个性格画像
                                                              │
                                                    随机森林分类（画像预测）
                                                              │
Spotify 数据 ─► 去重/特征工程 ─► 流行度回归（线性回归 vs 随机森林）
                                                              │
                                        画像 × 流派偏好（Kruskal-Wallis 检验）──► 代表歌手
```

- **数据清洗**：150 列中 144 列存在缺失，总缺失率 0.4%，量表题中位数填补、分类题众数填补；
  文字选项题（守时、诚实度）序数编码为 1-5 分；合成 **大五人格代理指标**
  （外向社交 / 尽责自律 / 情绪稳定 / 开放好奇 / 宜人友善），情绪稳定维度做反向计分。
- **聚类**：K-Means（肘部法则 + 轮廓系数定 K），层次聚类（Ward）作算法一致性对比（ARI）。
- **分类**：逻辑回归 / 决策树 / 随机森林，5 折分层交叉验证，混淆矩阵 + 特征重要性。
- **回归**：线性回归（基线）/ 随机森林，5 折交叉验证，R²/RMSE/MAE + 消融对比。
- **统计检验**：Kruskal-Wallis 非参数检验验证画像间流派偏好差异是否显著。
- 技术栈：Python 3.12、pandas、NumPy、scikit-learn、SciPy、Matplotlib、Seaborn、Jupyter、Git。

## 四、核心结论

### 结论 1：年轻人可分为 3 个性格画像（K-Means，K=3，轮廓系数 0.170）

| 性格画像 | 人数 | 占比 | 人口学特征 |
|----------|------|------|-----------|
| 开放好奇·宜人友善型 | 359 | 35.5% | 女性 73%，平均 20.7 岁 |
| 情绪稳定·外向社交型 | 343 | 34.0% | **女性仅 36%**（显著偏男性），平均 20.1 岁 |
| 尽责自律·宜人友善型 | 308 | 30.5% | 女性 69%，平均 20.5 岁 |

> 诚实披露：所有 K 的轮廓系数均低于 0.2，说明年轻人的性格**不存在泾渭分明的分群**，
> 画像之间存在重叠。这是真实人格数据的普遍特征，项目采用「轮廓系数 ≥ 最优值 90% 的最大 K」
> 规则在可接受的质量损失内换取更细的划分粒度。

### 结论 2：性格画像与音乐口味显著相关（Kruskal-Wallis 检验）

17 个流派中 **15 个**在画像间的偏好差异达到 p<0.05 显著水平，差异最大的是
音乐剧（H=82.2）、歌剧（77.6）、拉丁（65.2）、爵士（61.8）、古典（61.8）。

### 结论 3：什么性格的年轻人喜欢什么歌手（核心结论表）

| 性格画像 | 特征流派 | 代表歌手 |
|----------|----------|----------|
| **开放好奇·宜人友善型** | 拉丁、R&B（问卷侧最爱音乐剧、爵士、古典、歌剧） | Shakira、Maluma、Romeo Santos、Billie Eilish、SZA、Frank Ocean |
| **情绪稳定·外向社交型** | 说唱、电子舞曲 | Kendrick Lamar、Young Thug、Trippie Redd、Timmy Trumpet |
| **尽责自律·宜人友善型** | 流行（各流派偏好均衡，无突出偏好） | Ed Sheeran、Coldplay、Camila Cabello、5 Seconds of Summer、Khalid |

**业务解读**：偏爱古典/爵士/音乐剧的「开放好奇」人群同时最接受拉丁与 R&B；
而「外向社交」人群明显偏向节奏感强的说唱与电音。这为冷启动推荐提供了可用的先验规则。

### 结论 4：画像可以被预测（分类）

用年龄、性别、学历、上网时长、44 项兴趣爱好等**易得信息**预测性格画像：

| 模型 | 准确率 | 宏平均 F1 |
|------|--------|-----------|
| 基线（全猜最多类） | 35.5% | — |
| 逻辑回归 | 67.6% | 0.674 |
| 决策树 | 57.3% | 0.571 |
| **随机森林** | **69.2%** | **0.686** |

随机森林相对基线**提升 33.7 个百分点**。最重要的预测特征是极限运动、艺术展览、
戏剧、跳舞——即「生活方式即音乐口味的镜像」。

### 结论 5：歌曲流行度的可预测性有限（回归）

| 模型 | 特征集 | R² | RMSE |
|------|--------|-----|------|
| 线性回归 | 仅音频+年份 | 0.057 | 23.02 |
| 随机森林 | 仅音频+年份 | 0.135 | 22.04 |
| 线性回归 | 音频+年份+流派 | 0.087 | 22.64 |
| **随机森林** | **音频+年份+流派** | **0.173** | **21.56** |

- 加入流派信息后 R² 从 0.135 提升到 0.173，说明流派是有效信号；
- **发行年份是最重要的预测因子**（重要性 0.129），反映流行度指标的「新歌优势」；
- 音频特征与流行度的相关系数全部弱于 |0.15|（时长 -0.14、器乐度 -0.12 为负相关），
  说明**歌曲走红主要不由音频特征决定**——这与学术界「流行度受市场、宣发、社交传播影响」的结论一致。

## 五、项目亮点（面试可讲的技术点）

1. **避免了信息泄漏**：回归建模前按 `track_id` 去重（原始数据 32833 行中有 4477 行是同一首歌
   出现在多个歌单），否则同一首歌会同时进入训练集与测试集，导致 R² 虚高。
2. **避免了循环论证**：分类任务的特征刻意排除 5 个性格维度本身（画像由它们聚类而来）
   与 17 个流派打分（音乐口味是待预测结果），只用人口学与兴趣爱好做预测。
3. **统计显著性把关**：不只看均值差异，用 Kruskal-Wallis 检验筛掉 2 个不显著流派
   （朋克 p=0.24、金属/硬摇 p=0.42），避免把噪声当结论。
4. **相对偏好而非绝对偏好**：所有画像的绝对偏好都以流行乐居首，改用「相对全体均值」后
   才显露出画像差异，并如实标注「尽责自律型各流派偏好均衡、无突出偏好」。
5. **消融实验**：通过「仅音频 vs 音频+流派」的对比量化流派特征带来的 R² 增益。
6. **结论可复现**：全部脚本固定随机种子（`RANDOM_STATE=42`），一条命令重跑全流程。

## 六、项目局限（如实说明）

1. 问卷受访者为斯洛伐克 15~30 岁年轻人，音乐偏好属欧美体系，结论适用于欧美流行音乐语境；
2. 两份数据集**不是同一批人**，通过「流派」这一共同维度桥接，结论是**画像层面的群体倾向，
   不是个体因果关系**；
3. Spotify 数据集仅含 6 大流派，问卷中的民谣、乡村、古典、音乐剧、歌剧 5 个流派无对应歌手数据，
   不参与歌手映射（这 5 个流派恰好是画像差异最大的部分，是数据本身的限制）；
4. 性格维度为问卷单题合成的**代理指标**，非标准化大五人格量表（如 NEO-PI-R）。

`app.py`——「性格 × 流行歌手推荐器」：**带登录/注册**，
登录后可在侧边栏切换 3 个性格画像，实时查看该画像的性格雷达图、偏爱的流派与代表歌手


无需重跑分析**即可直接运行，也是它可以直接部署上云的原因。

#### 登录与注册

- **预置账号**配置在 `st.secrets` 里（本地 `.streamlit/secrets.toml`，线上在 Streamlit Cloud 面板配置），
  **绝不写进代码**——本仓库是公开的，把密码写进 `app.py` 等于发布到全网。
  可复制模板开始：`.streamlit/secrets.toml.example`
- **注册功能**：任何人可在「注册」标签自助创建账号，带图形验证码；
  密码用 **bcrypt 哈希**存储，任何环节都不保存明文
- **注册用户持久化**：写入 `data/users.json`（已 gitignore）。
  这一点必须自己实现——`streamlit-authenticator` 的注册只更新内存字典、不落盘，
  而 Streamlit 每次交互都会重建认证对象，不落盘的话注册完一刷新就没了

> ⚠️ **线上持久化限制**：Streamlit Community Cloud 的文件系统是临时的，
> 应用重启或重新部署后 `data/users.json` 会被重置，**注册账号会丢失**
> （secrets 里的预置账号不受影响）。要真正长期保存用户需接外部数据库
> （如 Supabase/PostgreSQL），属后续扩展。
>
> ⚠️ **安全提示**：「必须登录」+「开放注册」的实际效果是"任何人注册一下就能进"，
> 防护意义有限，主要价值是演示完整的认证流程。

## 十、Git 版本管理与异地备份

项目使用 git 管理，按分析阶段分 9 次提交（初始化 → 数据 → 清洗EDA → 聚类 → 分类 → 回归 →
歌手映射 → 报告文档 → 修复），原始数据不入库（可脚本重新获取），图表与结果表入库。

推送到 GitHub 实现异地备份：

```bash
# 先在 GitHub 网页新建一个空仓库（不要勾选 README/.gitignore），然后：
bash scripts/setup_github.sh https://github.com/你的用户名/仓库名.git
```

> 国内网络若 SSH 22 端口不通，脚本注释中提供了 443 端口通道的替代命令。

**可复现性已验证**：把仓库克隆到新目录后，依次运行 `01`~`06` 脚本，
聚类、分类、回归、显著性检验的全部结果表与原始仓库**逐字节一致**
（固定随机种子 `RANDOM_STATE=42`）。
